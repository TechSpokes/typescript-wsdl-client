## Fixed value and representation contract

Decimal includes the existing qualified integer descendants. Retain existing member restrictions and list facet languages; do not widen source legality or trust syntax in place of native plans.

Ordinary JSON/TypeScript values are dense ordered arrays of lexical strings. JSON numbers, booleans, branch-tag objects, empty item strings and items containing XML whitespace refuse before dispatch. Do not trim an item to rescue it or split one application item into several tokens. An empty array is valid only when the selected native list constraints permit zero items.

XML-list whitespace separates tokens; ordinary arrays preserve token spelling and order, not original separators. Preserve signs, leading zeros, decimal scale and non-XML whitespace that the native string member actually permits. Do not use JavaScript trim/split conventions as an alternate tokenizer.

Each inverse reassesses every token through native effective-member order and member rules. Native union-facet failure after selecting a member remains terminal. No numeric coercion, branch sorting, caller-selected member or partial successful list is permitted.

Keep the existing single whole-list lexical-string representation when list-level witness rules require it. Do not replace those strings with arrays or convert ordinary arrays into strings. The native list, union and restriction owners continue to decide validity and member values.

Fixed, default and enumeration behavior uses existing native sequence typed equality. List canonical evidence already encodes each item's primitive family and canonical value; preserve that owner rather than implement array-string comparison. A string-selected `"1"` item differs from decimal-selected `"+1"`; decimal/integer aliases of equal value remain equal. Cover boolean/string collisions and item order as well.

Retain source lexical witnesses when inserting list defaults/fixed values so member choice cannot change. Preserve authenticated, deeply frozen transient operands, existing absent/present-empty augmentation, inherited attribute constraints, nil rules and portable source reconstruction.
