# TypeScript WSDL Client v1.12.0

## Checked generation in separate steps

Generate a checked OpenAPI document, Fastify gateway, runnable app and test scaffolds through separate commands or typed package APIs. See the [project README](../../README.md) and [standalone workflow](../checked-generation.md#generate-the-checked-stack-in-separate-commands).

## What This Improves

Teams can review the HTTP contract before generating a gateway and refresh app or test scaffolds independently. Each stage qualifies the original WSDL and imports. Gateway and app generation verify that the supplied files match the selected contract.

## Highlights

- Use `--model checked-components-v1` on the standalone `openapi`, `gateway`, and `app` commands.
- Call `generateCheckedOpenAPI`, `generateCheckedGateway`, and `scaffoldCheckedApp` from the package root.
- Preserve edited app and test files by default and refresh either with its own force option.

## Upgrade Notes

Legacy commands retain their default behavior. To migrate a catalog-based workflow, regenerate from the original WSDL and imports and keep the checked client, OpenAPI and gateway artifacts together.

## Validation

- The installed Forecast consumer compares CLI and API artifacts with the checked pipeline.
- The generated app typechecks, builds, runs its scaffold tests and supports relocation with production dependencies.
- Independent SOAP fixtures cover success, a declared fault, invalid upstream data and pre-dispatch refusals.
