# TypeScript WSDL Client v1.0.3

## Stable Dependency Tooling

Version 1.0.3 refreshes the SOAP runtime and TypeScript execution tooling while preserving the compiler compatibility required by repository validation and generated projects.

## What This Improves

The package and generated app scaffold now use `soap` 1.10.0 and `tsx` 4.23.1. These updates keep runtime SOAP integration and TypeScript execution current without changing generated client, OpenAPI, gateway, or app behavior.

TypeScript remains on the supported 6.x line because TypeScript 7 changes the compiler package exports and JavaScript API used by validation and conformance tests. Dependabot now defers only TypeScript 7.x updates until that compiler migration is implemented and validated separately.

## Highlights

- Updates the `soap` runtime dependency minimum to 1.10.0.
- Updates the `tsx` development dependency minimum to 4.23.1.
- Aligns generated app dependency pins with the refreshed root dependencies.
- Retains TypeScript 6.0.3 compatibility for compiler API and CLI validation.
- Defers TypeScript 7.x Dependabot updates pending a dedicated migration.

## Upgrade Notes

No generated-code or public API changes are introduced. Existing consumers can update normally, and newly generated apps receive the refreshed `soap` and `tsx` dependency ranges.

## Validation

- CI passed.
- The complete WSDL capability conformance suite passed.

## Notes

Release tag: `v1.0.3`.

TypeScript 7 adoption remains a separate maintenance task because its native compiler package does not preserve the TypeScript 6 JavaScript compiler API and CLI export behavior used by this repository.
