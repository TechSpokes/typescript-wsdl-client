## Faster verification before delivery

This patch reduces the time contributors wait for CI and clarifies how a reviewed candidate becomes a release draft.

## What This Improves

Routine pull requests retain the full Linux delivery gate and use representative installed-package checks on Windows and the current Node line. Verification cleans its temporary workspaces and restores the preceding local build. Maintainers can request the complete installed compatibility matrix when they need it.

## Highlights

- Validate the actual npm tarball through legacy generation and checked gateway execution over TLS.
- Share generated app dependencies for equivalent test variants while preserving independent wire assertions.
- Finish local checks and review before opening or updating a pull request, including a draft.
- Stop release preflight before expensive stages if prerequisites fail. Verify merged main before tagging.

## Upgrade Notes
