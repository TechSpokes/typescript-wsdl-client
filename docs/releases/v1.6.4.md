Consumers using `noUncheckedIndexedAccess` can compile selected-header and status-only gateways without relaxing their TypeScript configuration or editing generated files. Existing runtime selection, naming and privacy contracts remain unchanged.

- Compile generated consumers with strict indexed access and exact optional property checks in regression coverage.
