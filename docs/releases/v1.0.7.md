# TypeScript WSDL Client v1.0.7

## Security and dependency maintenance

This patch release applies upstream security fixes in XML, URI, and OpenAPI parsing dependencies, refreshes maintained dependency floors, and keeps generated-test verification compatible with the latest Vitest output format.

## What This Improves

The XML and URI parser updates address upstream security fixes, while the OpenAPI parser and YAML updates keep the internal validation stack current. Generated applications and repository tooling also start from refreshed dependency floors.

Generated-test verification now reads Vitest's JSON report file directly, preserving consumer-style test evidence as the test runner evolves. The Node 26 stream test also waits for the readable stream to close before checking source iterator cleanup.
