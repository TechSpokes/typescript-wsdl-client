# TypeScript WSDL Client v0.40.1

## Faster Conformance Feedback Before 1.0

This maintenance release makes the capability conformance suite easier to run and diagnose while closing the remaining scope decisions before the stable 1.0 release candidate.

## What This Improves

Maintainers and contributors can run contracts, compile, client, OpenAPI, gateway, generated-test, or app conformance independently instead of waiting for every evidence layer after a focused change. The complete release-blocking suite remains intact and now reports visible per-capability progress during its longer generated-project checks.

The 1.0 boundary is also explicit. Multiple bindings retain deterministic first SOAP binding selection, external policy documents remain unresolved, abstract types and substitution groups remain diagnostic, and MTOM/XOP attachments remain outside the typed SOAP-to-REST transport contract.

## Highlights

- Adds stage-specific conformance commands for focused maintainer feedback.
- Keeps all 123 capability checks in the canonical full suite.
- Documents the expected full-suite duration and agent timeout guidance.
- Records the accepted partial and terminal capability boundaries for 1.0.
- Defers the public WSDL inspector until after 1.0.

## Upgrade Notes

No special upgrade steps. Generated client, OpenAPI, gateway, app, and runtime contracts are unchanged.
