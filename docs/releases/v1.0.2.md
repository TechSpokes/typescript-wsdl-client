# TypeScript WSDL Client v1.0.2

## The Complete Stable Typed SOAP Modernization Contract

Version 1.0.2 is the complete supported stable release narrative for the TypeScript client, OpenAPI 3.1, Fastify gateway, runnable app, test generation, and programmatic APIs developed throughout the 0.x series.

## What This Improves

Teams can adopt the generator with an explicit compatibility baseline. Default generated behavior remains aligned with `0.40.1`, supported WSDL patterns have fixture-backed evidence through every generated stage, and unsupported polymorphic or attachment constructs stop with diagnostics instead of producing misleading contracts.

The stable migration contract makes opt-in behavior clear. Choice unions remain optional, NDJSON remains the default streaming format, JSON arrays remain available per operation, and multiple SOAP bindings continue using deterministic first-binding selection.

Release delivery is now equally explicit. npmjs is the sole package registry, publication uses the tested npm 12 toolchain with provenance, and package validation accepts both npm 11 and npm 12 manifest formats. Rejected candidates keep immutable release and marker tags, while their maintainer-only draft releases may be retired after the remote marker is verified.

## Highlights

- Stabilizes typed SOAP clients, OpenAPI specifications, Fastify gateways, apps, and generated tests.
- Requires Node.js 24 or newer and keeps Node 26 compatibility coverage.
- Preserves `all-optional` as the default `xs:choice` strategy.
- Preserves NDJSON as the default configured streaming format.
- Supports per-operation JSON array streaming as an opt-in alternative.
- Carries fixture-backed conformance evidence across compile and generated consumer stages.
- Rejects abstract types, substitution groups, and MTOM/XOP attachments with explicit diagnostics.
- Documents deterministic multi-binding behavior and unresolved external policy references.
- Keeps the public WSDL inspector as a post-1.0 candidate.
- Publishes only to npmjs with OIDC provenance and a pinned npm release.
- Accepts package manifests emitted by npm 11 and npm 12.
- Retires abandoned drafts without deleting or reusing immutable tags.

## Upgrade Notes

No intentional generated-code or runtime behavior break is introduced relative to `0.40.1` or `1.0.1`. Consumers must run Node.js 24 or newer, regenerate owned output, review the generated diff, and run their TypeScript build and tests.

Install `1.0.2` as the current stable package. Existing `1.0.1` consumers may update without a migration.
