# TypeScript WSDL Client v1.11.0

## Measurable release verification

The release checks now report what GitHub actually tested and where installed consumer verification spends its time. Maintainers can use one reviewed PR for a change approved to ship immediately.

## What This Improves

Release preflight checks current npm dependency pins concurrently and still checks the lockfile and generated app pins before full delivery. The CI logs identify the checkout commit and tree so the maintainer can confirm which content passed on the PR and on main.

## Highlights

- Installed legacy and checked consumer tests report individual setup, compilation and wire phases.
- Checked-gateway runtime controls share one server module load while exercising fresh HTTP listeners.
- A read-only workflow rehearses transferring a validated npm tarball and checking its contents, identity and digest.
- The release procedure documents the combined and separate PR paths with examples from previous releases.

## Upgrade Notes

No special upgrade steps. The verification changes are internal to release tooling.

## Validation

- The release checks cover the source pipeline, independent SOAP evidence and isolated npm consumers.
- Release preflight validates the package and produces the standalone agent skill ZIP and checksum.
