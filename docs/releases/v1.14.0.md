# TypeScript WSDL Client v1.14.0

## ONVIF Media reads and declared wildcard attributes

Checked SOAP 1.2 gateways can qualify more ONVIF Media reads under `lax-wildcard-operation-v1`. The same scope validates supported declared string attributes on elements matched directly by a lax wildcard.

## What This Improves

A single gateway can list video sources, fetch stream and snapshot URIs for a profile, and list encoder and compatible encoder configurations. Encoder configurations preserve inherited fields and the ordering of optional fields before their required session timeout.

An extension such as the one used in `DeleteOSD` can carry a declared `xmime:contentType` attribute. Both encoding and decoding apply the pinned string restriction and preserve the attribute's expanded name and lexical value.

## Highlights

- Qualify inherited sequences with optional singletons before a required element and a trailing lax wildcard.
- Preserve supported declared string attributes on immediate opaque wildcard elements.
- Compare all 79 pinned Media operations against the published v1.13.0 planner.
- Replay the five read routes together and exercise the declared-attribute boundary separately.

## Upgrade Notes

Use `lax-wildcard-operation-v1` for these checked contracts. Regenerate the matched client, OpenAPI, and gateway together from the authorized snapshots. Whole-source and closed-operation checks retain their existing refusals. [Checked gateways](../checked-gateway.md#scoped-lax-wildcards)
