# TypeScript WSDL Client v1.1.3

## Updated dependencies for clients and gateways

This patch refreshes runtime and development dependencies and aligns generated app dependency ranges. See the [project overview](../../README.md) for the generation pipeline.

## What This Improves

The refreshed dependency tree addresses upstream HTTP transport, URI normalization, brace expansion, and source map advisories. Generated applications use the updated SOAP runtime range, and local development selects the supported Node 24 floor.

The compiler remains on TypeScript 6 to preserve compatibility with the lint tooling and compiler API validators. Generated client and gateway contracts remain unchanged.

## Highlights

- Refresh compatible runtime, development, and transitive dependencies.
- Align generated app SOAP runtime and Node type dependency ranges with the root package.
- Replace the stale Node 20 development pin with Node 24.
- Retain TypeScript 6 and the existing Node 24 minimum.

## Upgrade Notes

Update the package and refresh your dependency lockfile. Existing applications can update their SOAP runtime dependencies directly; regenerating an app scaffold preserves existing files unless explicitly forced.

TypeScript 7 is excluded from this release. No generated API or configuration migration is required.
