# TypeScript WSDL Client v1.0.1

## Reliable npmjs Publication for the Stable Contract

Version 1.0.1 delivers the stable contract intended for 1.0 with corrected npm 12 package validation and an npmjs-only release path.

## What This Improves

Maintainers can publish with the tested npm 12 toolchain without the package-content validator rejecting npm's package-keyed JSON output. The validator remains compatible with npm 11 for local and maintenance workflows.

Package delivery now has one authoritative registry. The guarded release workflow publishes only to npmjs with provenance and no longer grants or uses GitHub Packages capability.

## Highlights

- Preserves the stable TypeScript, OpenAPI, Fastify, app, test-generation, and programmatic contracts.
- Accepts the package manifest formats emitted by npm 11 and npm 12.
- Pins the tested npm release used by publication automation.
- Publishes packages only to npmjs with provenance.
- Removes the legacy GitHub Packages distribution and prevents recreation.
- Keeps the abandoned `v1.0.0` candidate and marker as immutable release evidence.

## Upgrade Notes

No generated-code or runtime migration is required relative to `0.40.1`. Consumers must continue using Node.js 24 or newer.

Version `1.0.0` was permanently abandoned before npmjs publication. Install `1.0.1` as the first supported stable package.
