# TypeScript WSDL Client v1.0.4

## Secure Dependency Delivery

Version 1.0.4 is the next public patch after the retired v1.0.3 candidate. It refreshes SOAP and TypeScript execution tooling, remediates vulnerable direct and transitive dependencies, and updates release workflows without changing generated client, OpenAPI, gateway, or app behavior.

## What This Improves

The package and generated app scaffold now use `soap` 1.10.0 and `tsx` 4.23.1. The direct `fast-xml-parser` and `js-yaml` dependency floors are updated to secure versions, while the refreshed lockfile resolves the reported Axios, brace expansion, routing, URI, and YAML advisories.

TypeScript remains on the supported 6.x line because TypeScript 7 changes compiler package exports and JavaScript APIs used by validation and conformance tests. Dependabot continues to defer only TypeScript 7.x updates until that compiler migration is implemented and validated separately.

GitHub Actions workflows now use `actions/setup-node` v7. Security reporting guidance is aligned with Node.js 24 and GitHub private vulnerability reporting.

## Highlights

- Updates the `soap` runtime dependency minimum to 1.10.0.
- Updates the `tsx` development dependency minimum to 4.23.1.
- Updates `fast-xml-parser` to 5.10.1 and `js-yaml` to 5.2.2 or newer compatible releases.
- Refreshes transitive HTTP, brace expansion, routing, URI, and YAML dependencies.
- Aligns generated app dependency pins with the refreshed root dependencies.
- Retains TypeScript 6.0.3 compatibility for compiler API and CLI validation.
- Defers TypeScript 7.x Dependabot updates pending a dedicated migration.
- Upgrades GitHub workflows to `actions/setup-node` v7.

## Upgrade Notes

No generated-code or public API changes are introduced. Existing consumers can update normally, and newly generated apps receive the refreshed `soap` and `tsx` dependency ranges.

Users upgrading from v1.0.2 receive the dependency tooling changes originally planned for v1.0.3 together with the security remediation in this release. Version 1.0.3 was retired before publication and never shipped to npm.
