# TypeScript WSDL Client v1.0.0

## A Stable Typed SOAP Modernization Contract

Version 1.0 declares the documented TypeScript client, OpenAPI 3.1, Fastify gateway, runnable app, test generation, and programmatic APIs stable after the complete 0.x implementation and conformance program.

## What This Improves

Teams can adopt the generator with an explicit compatibility baseline. Default generated behavior remains aligned with `0.40.1`, supported WSDL patterns have fixture-backed evidence through every generated stage, and unsupported polymorphic or attachment constructs stop with diagnostics instead of producing misleading contracts.

The migration contract also makes opt-in behavior clear. Choice unions remain optional, NDJSON remains the default streaming format, JSON arrays remain available per operation, and multiple SOAP bindings continue using deterministic first-binding selection.

Release delivery now preserves rejected candidate evidence. An annotated abandonment marker blocks draft mutation and package publication while consuming the rejected version permanently.

## Highlights

- Stabilizes typed SOAP clients, OpenAPI specifications, Fastify gateways, apps, and generated tests.
- Requires Node.js 24 or newer and keeps Node 26 compatibility coverage.
- Preserves `all-optional` as the default `xs:choice` strategy.
- Preserves NDJSON as the default configured streaming format.
- Carries fixture-backed conformance evidence across compile and generated consumer stages.
- Rejects abstract types, substitution groups, and MTOM/XOP attachments with explicit diagnostics.
- Documents deterministic multi-binding behavior and unresolved external policy references.
- Keeps the public WSDL inspector as a post-1.0 candidate.
- Blocks GitHub Packages and npm publication for permanently abandoned release candidates.

## Upgrade Notes

No intentional behavior break is introduced relative to `0.40.1`. Consumers must run Node.js 24 or newer, regenerate owned output, review the generated diff, and run their TypeScript build and tests.
