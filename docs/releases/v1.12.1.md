# TypeScript WSDL Client v1.12.1

## Checked artifact paths and source diagnostics

Checked apps support literal `#` and `%` in client and gateway directory names. Checked generation also reports missing WSDL ports and includes the native reason when schema qualification refuses.

## What This Improves

A generated app can start with the artifact layout you selected, and the scaffold tests run through the usual test command before a build. When generation stops at the source, the diagnostic identifies whether the WSDL lacks a service port or a native source rule failed.

## Highlights

- Keep literal client and gateway paths through generation, strict build, runtime loading, and regeneration.
- See native schema rule and declaration details in checked planning diagnostics when available.

## Upgrade Notes

If your checked app uses an affected path, regenerate the matching artifacts and refresh its host and tests. For customized scaffolds, apply the loader changes from freshly generated files and retain your edits. See [checked generation](../checked-generation.md#generate-the-checked-stack-in-separate-commands).
