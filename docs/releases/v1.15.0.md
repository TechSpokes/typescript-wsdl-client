# TypeScript WSDL Client v1.15.0

## Checked SOAP records as they arrive

Opt in per operation to stream validated records from supported SOAP 1.1 document/literal responses. Generated TypeScript clients expose typed records and a terminal outcome. Generated Fastify gateways emit NDJSON or JSON arrays.

## What This Improves

Consumers can process the first validated record while the SOAP server is still sending the response. The stream reports completion after validating the selected response scope and reaching clean XML and HTTP completion. A late upstream failure aborts HTTP delivery.

## Highlights

- Select records by a source-qualified path and publish their item schema in OpenAPI.
- Validate the declared response wrapper and support an explicitly configured companion grammar with documented scope.
- Apply caller-selected limits and cancel the upstream request when the consumer stops.
- Preserve QName meaning and enforce XML limits on the complete outgoing SOAP envelope.

## Upgrade Notes

Existing buffered clients can upgrade without changing their configuration. To enable streaming, add an operation to `checkedComponents.streams` and regenerate the client, capsule, OpenAPI document, and gateway together.

The streaming transport supports credential-free SOAP 1.1 document/literal over HTTP(S). Authorize the SOAP endpoint through `allowEndpoint` in the client or `allowedEndpoints` in the generated app. [Checked streaming guide](../checked-gateway.md#checked-streaming)

## Validation

- Strictly built, relocated package consumers receive a first item in both HTTP formats before the SOAP response ends.
- Installed checks cover terminal success, late abort, truncated HTTP framing, cancellation, and the published v1.14.0 buffered client.
- Release verification checks the package contents, generated examples, and agent skill artifact.
