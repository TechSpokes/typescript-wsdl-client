# TypeScript WSDL Client v1.16.0

## Hosted WSDL imports on Windows

Default generation on Windows now resolves relative XSD imports from hosted WSDLs over HTTP(S).

## What This Improves

Pass the service's WSDL URL directly to `--wsdl-source`, including URLs ending in `?wsdl`. The generator reads the companion schemas from their hosted locations.

## Highlights

- Resolve remote imports and includes relative to the WSDL or XSD that declares them.
- Follow the updated README to generate a client from either a local file or a hosted WSDL.

## Upgrade Notes

Upgrade the generator to v1.16.0 and regenerate from the original WSDL URL. Existing local WSDL paths and absolute HTTP(S) imports continue to work.

## Validation

- Default CLI coverage generates a client with the imported type from a loopback HTTP fixture.
- Control cases cover the original local fixture and an absolute HTTP schema URL.
- A redirect case covers a nested, query-relative XSD include.
- Release verification checks the package contents, generated examples, and agent skill artifact.
