# TypeScript WSDL Client v0.39.0

## IDE And Generated Output Hygiene

This release tightens the repository's TypeScript ownership model for tests, generated examples, and release scripts while keeping generated client and gateway behavior stable.

## What This Improves

Developers working in strict NodeNext IDEs get diagnostics that line up with the repository's actual test boundaries. Scoped TypeScript configs now own conformance tests, unit tests that import scripts, and generated example output without broadening the production `src` configuration.

Generated Fastify gateway runtime metadata is emitted with less duplicated source while preserving the same response envelope behavior. Release scripts also share file helpers so future packaging and validation changes have fewer duplicated paths to maintain.

## Highlights

- Adds scoped TypeScript ownership for tests and generated examples.
- Deduplicates generated gateway runtime metadata literals.
- Keeps gateway runtime response behavior stable.
- Refactors agent skill build and validation scripts around shared file helpers.
- Documents intentional IDE suppressions where local inspections disagree with verified runtime behavior.
- Polishes Markdown and consumer guidance wording.
