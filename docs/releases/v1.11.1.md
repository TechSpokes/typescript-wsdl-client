# TypeScript WSDL Client v1.11.1

## Verified npm archive delivery

The release build validates the npm archive and passes those exact bytes to the trusted publisher. Windows installed-consumer checks also run sooner by executing independent verification steps concurrently.

## What This Improves

The publisher checks the release tag, build attempt, package identity, and archive digest before submitting the archive to npm. Maintainers can trace the published package to the build that validated it.

## Highlights

- The npm workflow verifies the transferred archive before publishing it with provenance.
- Windows smoke runs declaration navigation, app type checking, and generated tests concurrently in the isolated consumer.
- The verification runner preserves an owned workspace when it cannot confirm that a child process tree stopped.
