# TypeScript WSDL Client v1.0.5

## Verifiable Agent Skill Delivery

This patch release makes the agent skill release artifact reproducible, checksummed, attested, and independently installable while refreshing maintained dependencies and remediating all current audit findings.

## What This Improves

Agent skill releases now include a deterministic ZIP, a conventional `SHA256SUMS` file, and GitHub build provenance. The draft workflow downloads its own uploaded assets into a clean directory, verifies their checksum and attestation, installs the skill in isolation, and exercises a representative weather WSDL pipeline.

Forced skill installation is now an exact, rollback-safe replacement. Existing installations remain untouched without `--force`; with `--force`, stale and locally modified files are removed as the complete candidate replaces the prior copy.

Behavior fixtures now cover command selection, generated-output refusal, environment guidance, and incomplete WSDL or catalog input. Incomplete-input guidance directs agents to inspect the consumer project before asking only for the missing source location and intended generation surface.

## Highlights

- Add deterministic agent skill archives, checksums, inventory validation, source-map validation, and MIT license metadata.
- Add release provenance and clean-runner verification of downloaded draft assets.
- Verify previous-release-to-candidate replacement without altering host or global configuration.
- Retain the release ZIP as the supported installation and update boundary while recording GitHub CLI dry-run compatibility.
- Refresh maintained direct dependency floors and remediate current transitive vulnerability alerts.

## Upgrade Notes

This release does not change the TypeScript API, generated-client contract, or `wsdl-tsc` CLI behavior. Package consumers can update normally.

Agent skill users should continue installing from the release ZIP. Install to an explicit target outside the extracted archive, and use `--force` only when a complete replacement of an existing installation is intended.
