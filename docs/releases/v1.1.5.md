# TypeScript WSDL Client v1.1.5

## Checked direct-client execution with explicit host control

This patch adds an opt-in, versioned package-root binding for independently installed checked direct clients. It also advances native WSDL/XSD qualification and research diagnostics while retaining the existing generated-client and gateway defaults.

## What This Improves

Generated checked direct clients can import `checkedDirectRuntimeV1` from the installed package root and execute supported document/literal SOAP 1.1 requests against explicitly authorized owned IPv4-loopback services. Native schema, scalar and payload validation, source identity, and compatibility checks remain in force. Typed response values and declared SOAP faults are independently exercised through installed-client tests.

Normal generated calls no longer inherit profiling work quotas, payload caps or default deadlines. Applications may deliberately select capacity limits, cancellation, deadlines and size controls according to their own operational requirements.

The checked path is deliberately narrow. It does not enable arbitrary production SOAP endpoints, remote source loading, TLS/authentication/WS-Security, general XSD support or public admission of unqualified operations. The broader content-model research and mathematical decision procedures remain separate from production support claims.

## Highlights

- Export the versioned `checkedDirectRuntimeV1` binding from the package root for installed checked direct clients.
- Preserve source-authorized native-plan and schema checks when constructing and invoking supported generated clients.
- Exercise ordered scalar requests, responses and declared SOAP faults through an owned local SOAP 1.1 adapter.
- Remove inherited profiling quotas and default execution ceilings from ordinary calls while keeping explicit caller-selected controls.
- Improve direct-schema correspondence, original-source reconstruction, diagnostic evidence and reference conformance without changing legacy defaults.
- Refresh the compatible dependency and generated-app pins, including security fixes for the transitive URI parser and HTTP client.

## Upgrade Notes

Update the package to `1.1.5` and regenerate checked clients when using the new binding. Existing client and gateway defaults remain unchanged. Do not direct the restricted checked runtime to production or third-party SOAP endpoints; unsupported grammar, source, scalar, binding and endpoint cases continue to refuse execution.
