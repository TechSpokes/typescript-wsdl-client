# TypeScript WSDL Client v1.13.0

## Scoped lax wildcards for SOAP 1.2

Checked generation can qualify selected SOAP 1.2 operations whose payloads include supported lax element and attribute wildcards. The release qualifies ONVIF Media `GetSnapshotUri` using the original pinned graph.

## What This Improves

A generated gateway can return the declared snapshot URI fields alongside vendor extension data. Known extension declarations are checked against the same pinned schema. Unknown content retains its expanded names, lexical values and order.

## Highlights

- Set `"qualificationScope": "lax-wildcard-operation-v1"` in checked configuration.
- Use supported lax attribute wildcards and element wildcards after a fixed required sequence.
- Reconstruct the selected operation and its wildcard checks from authorized physical snapshots at runtime.

## Upgrade Notes

Regenerate the matched client, OpenAPI and gateway together when opting into the new scope. `closed-operation-v1` still refuses selected wildcard dependencies. See [scoped lax wildcards](../checked-gateway.md#scoped-lax-wildcards).

## Validation

- Installed `GetSnapshotUri` uses 11 original pins and an owned SOAP 1.2 server after strict build and relocation.
- Verification covers typed and lexical extension values, SOAP faults, and invalid upstream responses.
- Whole-source, closed-operation, endpoint and snapshot refusal controls protect the dispatch boundary.
