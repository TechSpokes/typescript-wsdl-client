# TypeScript WSDL Client v1.0.6

## Security and Dependency Maintenance

This patch release applies the Fastify 5.12.1 security fixes and refreshes maintained runtime, development, and generated application dependencies.

## What This Improves

Consumers and generated Fastify applications now resolve the current Fastify security patch. The generated application scaffold also uses the maintained `soap` and Node type floors.

Repository validation now runs on Vitest 4.1.11 and current parser, YAML, SOAP, and Node type dependencies. These updates keep the supported Node 24 and Node 26 lines current without changing generated contracts.

## Highlights

- Apply the Fastify 5.12.1 security release.
- Update Vitest to 4.1.11 for current test-runner fixes.
- Refresh `fast-xml-parser`, `js-yaml`, `soap`, and `@types/node` dependency floors.
- Refresh generated app pins for Fastify, `soap`, and `@types/node`.

## Upgrade Notes

This release does not change the TypeScript API, generated-client contract, or `wsdl-tsc` CLI behavior. Package consumers can update normally.
